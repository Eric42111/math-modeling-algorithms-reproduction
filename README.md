## 数学原理速查

### 1. 最小二乘闭式解

对数据点 $(x_i, y_i)$ 拟合 $y = ax + b$，最小化残差平方和
$$S(a,b) = \sum_{i=1}^{n}(y_i - ax_i - b)^2$$

令偏导为零，解得：

$$a = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sum (x_i - \bar{x})^2}, \qquad b = \bar{y} - a\bar{x}$$

拟合优度：
$$R^2 = 1 - \frac{SS_{res}}{SS_{tot}} = 1 - \frac{\sum (y_i - \hat{y}_i)^2}{\sum (y_i - \bar{y})^2}$$

**两个关键性质**
- 拟合直线必定经过 $(\bar x, \bar y)$ —— 可用作计算对错的快速校验
- 最小化的是**竖直方向（y 方向）残差**，不是点到直线的垂直距离（后者是正交回归/总最小二乘）

**为什么用平方而不是绝对值**
- 平方处处可导 → 有闭式解；绝对值在 0 点不可导，只能迭代
- 平方对大误差惩罚更重（误差 2 倍，惩罚 4 倍）
- 直接求和 $\sum e_i$ 会正负抵消（实测输出 `-0.0000`），无法作目标函数

### 2. GM(1,1) 灰色预测

| 步骤 | 操作 | 原理 |
|------|------|------|
| 1 | 累加生成 AGO | 杂乱序列累加后露出指数趋势 |
| 2 | 紧邻均值 | 前后两点平均，等价于梯形面积代替矩形，减小离散化误差 |
| 3 | 最小二乘估参 | 解 $x^{(0)}(k) + a z^{(1)}(k) = b$ —— **与算法 1 同一套数学** |
| 4 | 时间响应 + 累减还原 | 白化方程的解还原回原始尺度 |
| 5 | 后验差检验 | 后验差比 C + 小误差概率 P 共同定级 |

**使用前提（级比检验）**：$\sigma(k)=\dfrac{x^{(0)}(k-1)}{x^{(0)}(k)}$ 应落在 $\left(e^{-\frac{2}{n+1}}, e^{\frac{2}{n+1}}\right)$ 内。
**适用边界**：小样本（4–15 点）、贫信息、单调趋势；外推期数 ≤ 原始数据量的 1/3。

### 3. TOPSIS 综合评价

贴近度：
$$C_i = \frac{D_i^-}{D_i^+ + D_i^-}$$

其中 $D_i^+$、$D_i^-$ 分别为方案 $i$ 到正理想解 $V^+$ 与负理想解 $V^-$ 的欧氏距离。

**七步流程**：指标正向化 → 向量归一化 → 加权 → 定理想解 → 算距离 → 算贴近度 → 排序 + 敏感性分析

**注意事项**
- **先正向化、后标准化**，顺序不可颠倒
- 成本型转极大型有极差变换（$x'=\max-x$）与倒数变换（$x'=1/x$）两种，结果不同
- TOPSIS 只给**相对排序**，$C=0.8$ 不代表「好」，只代表「在这批方案里最好」
- 权重是主观给的，**必须做敏感性分析**，否则结论脆弱
